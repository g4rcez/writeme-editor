The blank page myth

There is no blank page. Every thought you sit down to write already exists somewhere in your head — the editor's only job is to get out of the way while you retrieve it.

Write Me strips the interface to its minimum. No toolbar. No sidebar unless you want one. Just the cursor blinking in a clean 72-character column.

  • ✓ Open a new note
  • ✓ Write the first sentence
  • Stop editing, start thinking

// debounce with leading edge
function debounce(fn, wait) {
  let timer
  return (...args) => {
    clearTimeout(timer)
    timer = setTimeout(() => fn(...args), wait)
  }
}
